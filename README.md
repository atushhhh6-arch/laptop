# Birthday Burger Sponsors

Interactive 3D birthday burger-box sponsorship website.

## Deploy on Cloudflare Pages

- Connect this GitHub repository to Cloudflare Pages.
- Framework preset: **None**.
- Build command: leave blank.
- Build output directory: `/` (or `.` if Cloudflare asks for a relative directory).
- Deploy from the `main` branch.

The current checkout is a clearly labeled demo flow. Real USD payments are intentionally not enabled yet; the app is structured so Dodo Payments can be connected later.
